# Отправить файл с диска по почте

Кросс-сервисный сценарий: локальный файл -> письмо с вложением.

## Шаги

1. Уточни путь к локальному файлу и получателя.

2. Если нужно, проверь контекст письма: тему, краткий текст и дополнительные адреса.

3. Отправь письмо с вложением:

```bash
yacli mail send person@example.com "Счёт" "Во вложении файл" --attach ./invoice.pdf
```

4. Если файлов несколько, добавь `--attach` для каждого файла:

```bash
yacli mail send team@example.com "Документы" "Отправляю пакет файлов" --attach ./spec.pdf --attach ./quote.xlsx
```

## Заметки

- Перед отправкой убедись, что путь указывает на файл, а не на директорию.
- Если пользователь не дал тему, предложи короткую осмысленную тему вместо пустой строки.
- Если вложение чувствительное, явно проговори, кому и какой файл будет отправлен.
- MIME type определяется автоматически по расширению файла, но имя вложения берётся из локального имени файла.
